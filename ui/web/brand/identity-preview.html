WRAITH — Identity Directions

A brand system per direction (wordmark lockup + monogram/app-icon), not a single glyph. Pick a direction; wiring it in is one edit.

Designed to three attributes: forensic precision (constant-stroke, miter-sharp geometry), spectral (one restrained "revealed / vanishing" cue — never a mascot), and disciplined restraint (wordmark- and monogram-led, like Elastic / CrowdStrike / Wiz).

Honest medium note: LLM-authored SVG mascot illustration has a low ceiling — it reads amateur no matter the layering (that's why the two hand-drawn wraith creatures missed). What reads premium and is achievable in code is refined typography + precise geometry. These directions lead there. A literal, agency-grade illustrated spectre would need a vector tool (Illustrator / Figma) or an image generator — outside this offline code toolchain.

D1 · Stencil RECOMMENDED

Custom constant-stroke WRAITH, slightly condensed, miter-sharp — forensic and precise. Monogram is a full geometric W whose final upstroke ghosts to 40% (the single spectral cue). Minimal: wordmark + monogram, no extra symbol. Monogram is square + currentColor, so it drops straight into the existing TopBar/About lockup with zero layout change.
